# 📚 StudyForge

Upload a lecture or document and get study notes, flashcards and a quiz to help you memorize it.
Built with **Streamlit** (UI) and **Google Gemini Flash** (AI).

## Features

- **Upload** PDF, DOCX, PPTX, TXT or MD files (several at once), or paste a lecture transcript.
- **Notes**: structured Markdown notes (TL;DR, key concepts, detailed notes, memory aids, key takeaways). Choose concise, balanced or detailed. Download as `.md`.
- **Flashcards**: question-and-answer cards with a study mode. Mark each card "I knew it" or "Need review", then re-study only the missed cards until you know them all.
- **Quiz**: multiple-choice questions with scoring and explanations. Choose difficulty and number of questions.
- **Languages**: output in English, Urdu, Arabic, Hindi, French, Spanish or German.

## Setup

1. Install Python 3.10 or newer.
2. (Recommended) create a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Get a free Gemini API key at <https://aistudio.google.com/apikey>.

5. Provide the key in one of two ways:
   - Paste it into the sidebar when the app runs, or
   - Set it as an environment variable:

     ```bash
     export GEMINI_API_KEY="your-key"        # Windows (PowerShell): $env:GEMINI_API_KEY="your-key"
     ```

## Run

```bash
streamlit run app.py
```

The app opens at <http://localhost:8501>.

## How to use

1. Upload your files (or paste text) and click **Load material**.
2. Open the **Notes** tab and click **Generate notes**.
3. Open **Flashcards**, click **Generate flashcards**, and study until you know every card.
4. Open **Quiz**, generate a quiz and test yourself.

## Configuration

- **Model**: the sidebar defaults to `gemini-2.5-flash`. You can type any other Gemini Flash model name your API key supports, and you only need to change `DEFAULT_MODEL` in `app.py` to change the default.
- **Length limit**: text sent to the model is capped at 400,000 characters (`MAX_CHARS` in `app.py`).

## Tips for better memorization

- Generate notes first and read them once, then do flashcards.
- Repeat the **Review only missed cards** loop until you get 100%.
- Come back the next day and retry the quiz. Spaced repetition works better than cramming.

## Limitations

- Scanned PDFs (images only) contain no extractable text, so run OCR on them first.
- Content is generated by an AI model from your material. Check important facts against the source.
- Progress is stored only in the current browser session and is lost when you refresh the page.
